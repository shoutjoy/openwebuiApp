Academic Verified Search

-

학술 검색 결과 복사

APA 참고문헌과 초록을 검색해 Open WebUI 채팅에 붙여넣을 수 있는 자료로 만듭니다.

Google Scholar는 공식 공개 API가 없어 자동화 대상에서 제외하고, Semantic Scholar, Crossref, PubMed, arXiv, OpenAlex를 사용합니다. 검색 결과는 APA 형식과 초록 원문을 포함합니다.

OpenWebUI API 테스트

          
Flask 웹앱에서 로컬 OpenWebUI API로 메시지를 보내 응답을 확인합니다.

        

      

      

        

          
사용 목적

          
브라우저 UI에서 입력한 메시지가 Flask 서버를 거쳐 OpenWebUI API로 전달되는지 확인하는 간단한 연결 테스트입니다.

        

        

          
사전 조건

          
    
            
  • OpenWebUI 서버가 먼저 실행 중이어야 합니다.
    • 
            
  • 기본 OpenWebUI 주소는 현재 설정의 서버 URL을 사용합니다.
    • 
            
  • API 인증이 필요한 경우 `OPENWEBUI_API_TOKEN` 환경변수를 설정합니다.
